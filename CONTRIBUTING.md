# Contributing

Contributions are welcome through pull requests only.

The maintainer, [@jay-conquers](https://github.com/jay-conquers), reviews and approves every change before it is merged.

By submitting a contribution you agree that it is licensed under the GNU Affero General Public License v3.0 only, the same license as the rest of Rascal. There is no contributor license agreement.

Open an issue before a large change so the direction can be confirmed. Keep pull requests focused, and include a test when the change affects chat parsing, settings, tokens, or the overlay pages.
